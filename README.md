**Superstore Sales Analysis Dashboard**



**Project Overview**



This project analyses the Sample Superstore sales dataset using Microsoft Power BI. The dashboard provides insights into sales, profit, orders, product performance and regional performance.



**Objectives**



* Analyse overall sales and profit.
* Understand sales performance across categories and regions.
* Identify top-performing products.
* Explore monthly sales trends.
* &#x20;Compare customer segments.



**Tools Used**



* Microsoft Power BI Desktop
* Power Query
* DAX
* GitHub



**Data Cleaning**



* Imported the Superstore CSV dataset.
* Checked and corrected data types.
* Converted Order Date and Ship Date into the correct Date format.
* &#x20;Verified data quality before creating the dashboard.



**Key Performance Indicators**



* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Profit Margin
* 

**Dashboard Visualisations**



* Sales by Category
* Profit by Region
* Top 10 Products by Sales
* Profit by Sub-Category
* Sales by Segment
* Sales Trend



**Interactive Features**



The dashboard includes slicers for:



* Order Date
* Region
* Category
* Segment
